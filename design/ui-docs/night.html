Components / lm-card

lm-card

A paper ticket with a hard ink shadow. Holds a title slot, body copy and an optional stamp.

Usage #

Import once from the pinned tag, then drop the element in any page. It inherits --lm-ink and --lm-paper from the mode.

HTMLcard.html
<lm-card tone="marigold" tilt>
  <h3 slot="title">Lisbon, 06:40</h3>
  <p>Window seat, wheels up.</p>
</lm-card>

CSS custom properties #

CSSsite.css
/* override per card, both modes */
lm-card {
  --lm-card-tilt: -1.5deg;
  --lm-card-shadow: var(--lm-shadow-card);
}
