Accessibility

Note

The card is a grouping landmark only. Headings inside stay in the page outline. Do not put a second h1 on a docs page.

Warning

Tomato on paper is 3.74:1. Use tomato-d #a8321e for small text and links.

Tip

Reduced motion holds the first frame. The demo toggle sets data-motion="reduce" on the stage only.
