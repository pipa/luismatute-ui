Install

Install from a git tag. The version in the top bar comes from package.json.

Astro

Import the styles once in the layout. Register the elements in a client script. No runtime dependencies.

Bare imports

Link tokens.css, fonts.css and base.css. Keep scripts external. The site CSP hashes inline work.

Colour

Click a chip. The live region announces Copied.

Type

Bricolage Display for titles, Bricolage for body, IBM Plex Mono for chrome, Caveat only for a small handwritten accent.

Spacing

Use the published space scale. Docs chrome sits on 8, 12, 16, 20, 24 and 32.

Motion

Animate transform and opacity only. Honour prefers-reduced-motion and lm.ui.motion.

Illustrations

SVG kit from the takeoff page. Fills use token variables so they follow data-theme on the demo, not the docs shell.
